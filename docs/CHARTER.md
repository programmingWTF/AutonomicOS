## 0. 一句话定位

**在 Debian/Ubuntu 之上，做一个"Agent 原生层 + 一套默认值"的可安装系统：
不重写系统，而是让系统第一次把 Agent 当成自己的器官。**

| | AOS（旧，已作废） | Autonomic OS（本文件） |
|---|---|---|
| 第一性原理 | **不碰系统**：带外控制平面，附体在外部 | **成为系统的一部分**：原生、内生、有强制力 |
| 交付形态 | hypervisor 台架 + 外部控制平面 | **一个独立的、Agent 原生的 Linux 系统** |
| 与上游关系 | 数据平面零改动 | **衍生版形态**：骨头与绝大多数包复用 Debian/Ubuntu |
| 承诺 | — | research prototype：**只承诺"这个 release 当时能跑"** |

### 「独立系统」和「复用上游」不矛盾 —— 这条最容易搞错

**独立性看的是 5 样东西是不是我们的：**

1. **名字**
2. **发布物**（我们签名、我们发布）
3. **仓库**（我们自己的 apt 源）
4. **默认值**（关键，见 §1.3）
5. **一句承诺**（对外说清楚我们保证什么）

**跟"字节是不是我写的"无关** —— Ubuntu 的内核也不是 Canonical 写的。

**独立性是架构上的必要条件**：因为"原生"只能通过**默认值**实现，而默认值只属于独立系统。
一个 apt 源 + 一个默认安装的服务，就已经在改变默认值了；套在别人机器上改不了一个发行版的默认。

## 1. 第一性原理（不可违背）

### 1.1 复用不造骨头

Linux 内核 / glibc / GNU 基础工具 / systemd / dpkg+apt —— **一律沿用，不重写、不 fork**。

### 1.2 永不自己做的三样

**内核、init、C 库。**

eBPF 是"不改内核也能编程内核"的正路 —— 需要内核侧能力时用它，不用内核模块。

### 1.3 独立性 = 默认值必须是我们的

判据：装完我们的东西之后，系统的**默认行为**变了没有？
如果没变，我们只是一个能装的软件，不是一个系统。

### 1.4 无发行版级承诺，但"可复现构建"比承诺更重要

- 对外身份：**research prototype / reference implementation**
- 用 **release** 不用 channel（不做滚动更新，不做安全通告时间表）
- 但**构建必须可复现**：容器化 + 版本锁定 + CI

> **无承诺项目的典型死法是"只有作者的机器能编出来"。**
> 承诺可以没有，可复现不能没有 —— 那是我们唯一能给出的信用替代品。

### 1.5 一切副作用必经 Action 通道

可审计、可拒绝、可回滚；带**爆炸半径**（blast_radius）与 **`reversibility`** 分类。
（M1 只是埋下通道的形态，通道本身的强制力是后续里程碑的事。）

### 1.6 最终判据

**卖点不是"Agent 更强"，而是"Agent 第一次可以承担后果"。**

有回滚才敢放开权限；没回滚，越强的 Agent 越危险。
**它给 AI 的不是权限，是后果。**

## 2. 继承（AOS 的真资产，直接搬）

| 资产 | 内容 |
|---|---|
| **Action 抽象**（= Agent 的 syscall） | `preconditions / effect / postconditions / rollback / blast_radius / cost_estimate / idempotency_key / mode(dry_run\|apply\|verify)` + **`reversibility: none\|compensable\|exact`** |
| **带内 + 带外两条腿** | 带内 eBPF 看细节；带外给"重置世界"的权力 |
| **状态即服务** | 原始事件流 → 物化视图 → 按问题生成的摘要视图（**Agent 不直读 `/proc`**） |
| **世界 + 心智耦合快照** | 世界与 Agent 记忆打在同一时刻，一起回滚 |
| **世界版本号** | `world_version = (snapshot_id, action_seq)` —— 单调计数器放系统外，系统内置**只读**标记 → 可检测"绕过通道的漂移" |
| **T0–T3 延迟分层** | T0 µs 内核护栏 / T1 ms 脚本 / T2 s LLM / T3 min 人类 |

## 4. 项目亮点（按能否被演示排序）

1. **Agent 是系统的一等公民（身份，不是进程）**
   独立 UID / cgroup / systemd unit / 审计流 / 信任域。
   → *"Agent 不再是一个 App，而是系统认识的一个用户。"*
2. **一切副作用必经 Action 通道**：可审计 + 可拒绝 + 可回滚。
   → *"这个系统里没有未经审计的高危操作。"*
3. **可回滚是一等能力**：原子更新 + 快照 + 世界/心智耦合回滚。
   → *"它给 AI 的不是权限，是后果。"*
4. **观测即服务**：系统对 Agent 说 Agent 的语言，不读 `/proc`。
5. **系统级策略平面**：分级授权、提议-批准、不可逆标红（不是 prompt 里的红线表）。
6. **可复现 + 可回放**：构建可复现、运行可录制重放。
7. **形式是 remix，本质是一层**：不是第 300 个发行版，是能装在 Debian/Ubuntu 上的 **Agent 原生层**。
