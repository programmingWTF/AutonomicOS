# M3 · 从"能启动"到"能安装"

## 0. M3 只做一件事

**给 live 系统一条落盘的路：`autonomic-install`。**

做完这一步，"可以安装在计算机里的操作系统"是完整闭环：
ISO 启动 → 一条命令 → 关机拔盘 → 硬盘上就是 Autonomic OS。

---

## 1. 交付物

| # | 交付物 | 说明 |
|---|---|---|
| 1 | **`/usr/sbin/autonomic-install`**（live 系统内置） | 分区（GPT: ESP 512M + ext4）→ rsync 当前 live 系统 → fstab（UUID）→ GRUB（EFI `--removable`，不碰 NVRAM） |
| 2 | **`scripts/install-test.sh`** | 全自动装机验收：建带盘 VM → ISO 启动 → 落盘 → 关机拔盘 → 硬盘启动 → SSH 验收 |

刻意不做的：交互式分区向导、文件系统选择、语言时区问答 —— **默认值就是全部**，
这正是 CHARTER §1.3 的体现（安装器也是系统默认值的一部分）。

## 2. 验收实测（VirtualBox，8G VDI，2026-10-10）

```
ISO 启动 → autonomic-install /dev/sda（一条命令，含 10s 反悔倒计时）
→ 关机、摘 ISO、硬盘启动
→ os-release : Autonomic OS 0.1 (research prototype)
   hostname  : autonomic
   root on   : /dev/sda2          ← 硬盘 ext4，不再是 live overlay
   fstab     : UUID=... / ext4
   agent     : active（开机自启）｜ ssh: active
   world     : snapshot_id=bootstrap action_seq=0
```

---

## 3. 已知边界（诚实清单）

- **只支持 UEFI + GPT**（`--removable` 安装，不写 NVRAM）。BIOS/Legacy 没做。
- **整盘安装**，不做双系统/共存/分区大小自定义。
- 密码是 prototype 默认值（`guiyu/autonomic`），装完必须改。
- 安装器假设 `rsync` 可用且目标盘 ≥ 4 GB。
- 两次重启之间 SSH 就绪时间波动较大（150–300s），测试脚本按 210s 等待，偶有不够。
