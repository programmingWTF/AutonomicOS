## M5 🚧 Action 通道（CHARTER §1.5 的灵魂）

**核心洞察（写进代码注释了，也是整套设计的立身之本）：**
"AI 掌握底层"**不等于给 AI 一个 root shell** —— 那不是赋权，是等一个坏天气出事。
真正的做法是给它一条**比 shell 更有强制力**的通道，因为有约束所以才有力量。

架构（清晰的权限边界，两个守护进程）：
```
autonomic-agentd  uid=autonomic + ProtectSystem=strict —— 能思考，碰不到世界
        │  unix socket 0660 root:autonomic
        │  连上先查 SO_PEERCRED，请求字节还没解析就可能被拒
        ▼
autonomic-actd    root，但只认 4 个登记过的原语 + 4 个可写前缀
```

三个阶段，每个 action 必须回答三个问题而不是给一个承诺：
- **dry_run** 告诉你会发生什么，一个字节都不动
- **apply** 真的做，每步进 journal
- **verify** 事后回现场再数一遍 —— **verify 和 apply 不一致时 verify 赢**

每个 action 还要声明 `reversible`；不可逆的 action 需要额外一个显式开关才准做。

已登记的 4 个原语：`file.write` / `service.set` / `sysctl.set` / `self.test`

**写权限用白名单不用黑名单**（黑名单是"我能想出所有危险"，白名单是"我知道哪里安全"）：
```
可写: /etc/autonomic/  /etc/sysctl.d/  /etc/systemd/system/  /run/autonomic/
拒绝: /etc/shadow  /etc/passwd  /etc/sudoers  /etc/ssh/  （保险丝，冗余一层）
```

**闭环的关键（这是整套设计最值钱的一句）：**
apply 成功 → 给 agentd 发 SIGUSR1 → action_seq +1 → 投影更新 `/run/autonomic/world`。
**于是"世界版本号"是真实变更的账本，不是装饰** ——
绕过通道的改动不计数，这个差异本身就是漂移检测的信号。

**关于放行 root 的推理**（值得记住这个思路）：拒绝 root 没有安全收益（root 直接
kill 这个进程就行），但放行有好处 —— 管理员手动操作也会走通道留下审计记录和
版本号，而不是消失在一次 shell 里。**真正要拒的是第三者**（被攻破的服务、随机进程）。

## 本轮新踩的坑

1. **dh_install 装单个模板文件会变成同名目录**
   `debian/x.conf usr/share/autonomic` → 实测装出 `usr/share/autonomic/x.conf/x.conf`，
   postinst 里 `cp` 报 "omitting directory" → dpkg configure 失败 → 整轮构建白跑。
   **解法：不要这个中间环节，postinst 里直接 heredoc 写默认值。** 少一个环节少一个失败点。
2. **git-bash → wsl 内联命令里的 `$` 被吃掉**（本轮踩了两次）
   - `sh -c 'R=/x\ndu -sh $R/...'` → `$R` 变空，**静默地**去量了宿主系统的 /usr/lib
     （症状：结果看起来合理但路径不对 —— du 输出绝对路径而不是你拼的那个）
   - `... | awk "{print \$6}"` → awk 参数变空，报 syntax error
   **规律：凡涉及 `$`，一律写成 .sh 脚本文件，用
   `wsl -d Ubuntu -u root -- bash -c 'bash /mnt/d/.../x.sh'` 执行。**
   裸 `/mnt/` 路径参数还会被 MSYS 转成 `C:/Program Files/Git/mnt/...`，同样要套进引号。
3. **decorator 的 positional-after-keyword**
   `@register("file.write", reversible=True, (...))` → SyntaxError。
   改成 keyword-only 签名 `register(name, schema, *, reversible)`，读起来也更好：
   调用处看到 `reversible=False` 应该停顿一下，那是"这一步回头不了"的意思。
