### 今天新踩的坑（都在脚本注释和 LobsterContext 记忆里）
1. **WSL 的 `/tmp` 是 tmpfs**，实例终止即清空 → 中间产物必须落 `/root`
2. `mmdebstrap --variant=minbase` **不含 apt** → 必须 `--variant=apt`
3. chroot 继承 WSL 的 Windows PATH → 显式 export 纯净 PATH
4. rootfs 的 resolv.conf 是 resolved stub 的**符号链接**，`>` 重定向写不进 → 先 rm 链接再写
5. **debian 注释里写字面 `#DEBHELPER#`** 会被替换、破坏注释结构（混进过 M1 的包，已修）
6. VirtualBox `--firmware efi` 可能选 32 位 EFI → x64 #GP 崩 CpuDxe → 必须 `efi64`
7. 端口转发：`--natpf1 "名称,tcp,,宿主,,guest"`（无连字符、要名称）
8. **git-bash 调 wsl 裸路径参数被 MSYS 转换**（`/root/x` → `C:/Program Files/Git/root/x`）
   → 复杂操作写脚本文件，`wsl -- bash -c '...'` 执行
9. `${HOSTNAME:-默认}` 永远取不到默认（bash 内置变量）
10. headless 截图经常 0x0 → **串口日志才是真相**（grub.cfg 带 console=ttyS0）
11. live 系统 sshd 就绪要 150–300s，等待不够时先怀疑时机再怀疑功能
12. ISO 被 VM 挂着时 rm 失败 → 构建链第一步就断 → build.sh 只清 deb 不删整个 dist

## 定位复盘（23:5x，桂鱼问"到底是发行版还是包"）

实测数字（回答此类问题的依据，随时可复算）：
- rootfs 里 **207 个 dpkg 包，其中 autonomic 开头的只有 1 个**（autonomic-agent）
- 自研代码 **461 行**：autonomic-agentd 165 + autonomicctl 193 + autonomic-install 103
- ISO 238M，内核/systemd/glibc/apt 全部来自 Debian/Ubuntu 官方包

**结论：形态是发行版（有身份、有仓库、有安装器、能落盘），实质是一个包。**
准确叫法：**agent-native overlay for Debian/Ubuntu，以可安装 ISO 形态交付**。
不要对外宣称 "a new distro" —— 懂行的人会皱眉；也不要自卑，这个薄是 CHARTER
刻意设计的（"复用 Debian/Ubuntu 的骨头，只加一层默认值"）。

### 判定标准（什么时候才有资格叫"发行版"）
1. 自有包 ≥ 几十个（Mint 级）—— 现在 1 个
2. 安全更新通道：CVE 来了谁修、多久推 —— 现在全靠 Debian/Ubuntu 上游
3. 版本生命周期 + 升级路径（0.1 → 0.2 怎么升）—— 现在没有
4. 多架构 / 构建农场 —— 现在只有 amd64 + GitHub Actions
5. 治理与贡献者流程 —— 无

### 决策：不变厚
往右 Spectrum 挪一格的成本 = 重做 Debian 已经做成的事，而价值增量不在那里。
**继续往"深"走（Action 通道 / 世界模型），不往"宽"走。**
对外话术建议改："an agent-native overlay for Debian/Ubuntu, shipped as an
installable ISO"（README 待改，等桂鱼拍板）。

## 桂鱼的目标修正 + 实测数据（23:5x）

**桂鱼的新目标：做到"下游发行版级别"，但不承诺维护，只做开源项目。**

### 这个组合可行的唯一条件
把自己限制在 **overlay 形态**：
- 底层全是 Ubuntu noble 官方包，`-updates` / `-security` 源已在 sources.list 里
- → CVE 来了 Ubuntu 修，`apt upgrade` 自动到手；我们真正要维护的只有 1 个包 461 行
- → **"不承诺维护"因此在技术上成立**
- 反之：一旦 patch systemd / fork 内核 / 自己打包 GNOME → "不承诺维护"就是耍流氓，
  安全更新会在我们这一层断掉

结论：**做"发行版级别的形态"，保持"overlay 级别的责任"** —— 这两者的交集是自洽的。
反之"规模达到 Ubuntu 级别 + 不维护"是不自洽的。

### 待办（本次实测发现的两个真问题）
1. ⚠️ **ISO 里的 apt 源写死 `mirrors.aliyun.com`**（build-rootfs.sh 的 MIRROR 默认值，
   只为国内构建加速）。发布给别人用是错的 —— 国外用户慢，且观感差。
   发布用 ISO 应改为 `archive.ubuntu.com`，构建加速另想办法。
2. **var/cache/apt 有 111 MB 垃圾**（pkgcache.bin 56M + srcpkgcache.bin 56M）。
   **`apt-get clean` 不删这两个文件**，必须 `rm -rf /var/cache/apt/*`。
   清掉后 rootfs 643M → 532M，ISO 预计 237M → ~210M。

### 实测体积数据（回答"为什么比 Ubuntu ISO 小很多"）
| | ISO | rootfs 解压后 |
|---|---|---|
| Ubuntu Desktop 24.04 | 6.1 GB | ~4.5 GB |
| Ubuntu Server 24.04 | 2.5 GB | ~1.8 GB |
| Debian netinst | 0.6 GB | — |
| **Autonomic OS 0.1** | **237 MB** | **643 MB** |

rootfs 分项：modules 32M / x86_64-linux-gnu 65M / bin 49M / doc 9.8M / locale 7.5M / apt缓存 111M
最大包：linux-modules-generic 38M / locales 17M / linux-image 15M / libc6 13M / grub-common 13M

小的原因（按贡献排序）：① 无图形栈（**实测 Xorg/Xwayland/startxfce4/xsessions 全部 absent**，
GNOME+Mesa+GTK+字体≈1.5-2.5GB）② 无应用层软件（LibreOffice 单包就 500MB）③ 内核模块只有 32MB
（`linux-image-virtual`）④ 无完整 linux-firmware（~500MB）⑤ **Ubuntu 用 zstd 换启动速度，
我们用 xz -b 1M 换体积** ⑥ 我们的安装器是 103 行脚本，Ubuntu ISO 自带 Ubiquity+snap

### 测量方法的坑（新，重要）
git-bash 里 `wsl -- sh -c 'R=/x\n...'` **内联多行脚本的 $R 会被吃掉成空** → `du -sh $R/usr/lib`
退化成 `du -sh /usr/lib`，量的变成 WSL 宿主自己的 Ubuntu（错误读数 2.5G + Xorg + xfce.desktop）。
**规避：复杂测量一律写成 .sh 脚本文件，用 `wsl -d Ubuntu -u root -- bash -c 'bash /mnt/d/.../x.sh'` 执行。**
（这比记忆里已记的第 8 条"裸路径参数被 MSYS 转换"更隐蔽 —— 那次是路径，这次是变量变空，
症状是"结果看起来合理但是宿主的值"。**凡看到 du 输出相对路径/宿主绝对路径，就是变量丢了。**）

### 待办：安装向导与凭据（桂鱼的判断已确认要做）
- 凭据不是 nice-to-have 而是**通电开关**：agentd 现在 165 行、连不上任何 LLM，没凭据就是哑计数器
- 建议分两层：**装机 TUI**（磁盘/确认/时区/用户密码）+ **首次配置 first-boot**（BaseURL/APIKey/模型/连通测试，可跳过）
- TUI 用 **whiptail**（几十 KB），**绝不用 Calamares**（拖进几百 MB Qt 依赖，毁掉轻量优势）
- 凭据安全：`/etc/autonomic/credentials.env` chmod 640 root:autonomic，
  unit 里 `LoadCredential=autonomic-llm:...`，进程从 `$CREDENTIALS_DIRECTORY/` 读
- 依赖只用 python **标准库 urllib**，不引 requests
- 红线：**ISO 里绝不预置任何真实 key**
- 优先级：① 改 aliyun 源 ② 清 111M 缓存 ③ 凭据层+first-boot ④ 装机 TUI 放最后
  （装机 TUI 现在没第二个用户，ITC `autonomic-install /dev/sda` 够用）
