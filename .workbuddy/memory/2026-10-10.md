### 今天新踩的坑（都在脚本注释和 LobsterContext 记忆里）
1. **WSL 的 `/tmp` 是 tmpfs**，实例终止即清空 → 中间产物必须落 `/root`
2. `mmdebstrap --variant=minbase` **不含 apt** → 必须 `--variant=apt`
3. chroot 继承 WSL 的 Windows PATH → 显式 export 纯净 PATH
4. rootfs 的 resolv.conf 是 resolved stub 的**符号链接**，`>` 重定向写不进 → 先 rm 链接再写
5. **debian 注释里写字面 `#DEBHELPER#`** 会被替换、破坏注释结构（混进过 M1 的包，已修）
6. VirtualBox `--firmware efi` 可能选 32 位 EFI → x64 #GP 崩 CpuDxe → 必须 `efi64`
7. 端口转发：`--natpf1 "名称,tcp,,宿主,,guest"`（无连字符、要名称）
8. **git-bash 调 wsl 裸路径参数被 MSYS 转换**（`/root/x` → `C:/Program Files/Git/root/x`）
   → 复杂操作写脚本文件，`wsl -- bash -c '...'` 执行
9. `${HOSTNAME:-默认}` 永远取不到默认（bash 内置变量）
10. headless 截图经常 0x0 → **串口日志才是真相**（grub.cfg 带 console=ttyS0）
11. live 系统 sshd 就绪要 150–300s，等待不够时先怀疑时机再怀疑功能
12. ISO 被 VM 挂着时 rm 失败 → 构建链第一步就断 → build.sh 只清 deb 不删整个 dist
