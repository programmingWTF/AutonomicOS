### 关键技术决策
- **不引 aptly**：用 Debian 自带 `apt-ftparchive` + GPG 建仓库（第一性原理管工具链也一样）
- **日志命名空间用 systemd 原生 `LogNamespace=`**，不自己造日志文件
- **世界标记 0444 + 原子 replace**：计数器在系统外，系统内只有只读投影 → 漂移=证据
- **可复现三支柱**：SOURCE_DATE_EPOCH 固定 / 权限位在 ext4 临时目录里修正 / 基础环境锁定

### 本机环境坑（下次直接照抄）
1. WSL 里 apt 走 `127.0.0.1:7897` 代理 → 502（WSL 的 localhost 是它自己）
   → `apt-get -o Acquire::http::Proxy=DIRECT -o Acquire::https::Proxy=DIRECT`
2. `/mnt/d` 上所有文件 0777 → debhelper 把 `debian/install` 当**可执行配置**跑然后失败
   → `cp -a` 到 ext4 临时目录后再 chmod
3. `apt-ftparchive` 必须 cd 进仓库用**相对**路径，否则 Filename 写绝对路径 → apt 404
4. Windows 防火墙挡 VM→宿主 HTTP（NAT 网关 10.0.2.2）
   → 仓库 scp 进 VM，用 `systemd-run` 在 VM 内起 http.server
5. ssh 远程命令里 `&` 起后台进程会挂住会话 → 用 `systemd-run`
6. 宿主 `python -m http.server` 会锁目录 → `rm -rf repo/out` 报 Permission denied
7. WSL root：`wsl -d Ubuntu -u root`（sudo 要密码）；docker daemon 起不来 → CI 走 runner
